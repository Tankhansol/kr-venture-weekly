# KR Venture Weekly

국내 벤처투자 시장 주요 이슈를 주간단위로, 국내 벤처투자 통계를 월간단위로 정리하는 개인 운영 사이트입니다.

## 1. 무엇을 하는가

- **홈(`index.html`)**
  - 최신호 칼럼(히어로·Weekly Deals)
  - Recent Issues, Archive(검색·펼치기)
  - 국내 벤처투자 시장 동향(월간)
- **이슈 페이지(`issues/issue-NN.html`)**: 한 페이지에 Policy → Report → Deal → INSIGHT 순서로 표시. 상단 고정 목차로 섹션 이동, 0건 섹션은 생략
- **Deals(`deals.html`)**: 전 호의 딜을 한 표로 모아 지역 필터·검색(기업·섹터·투자자)·정렬(발표일, 금액). 같은 딜이 여러 호에 실리면 한 줄로 합치고 수록 호를 표시
- **데이터 분리:** 화면은 데이터 파일(`data/`)만 읽어서 그립니다. 내용 수정은 데이터 파일에서만 합니다.

## 2. 실행법

- **배포:** GitHub Pages가 `main` 브랜치 루트를 그대로 공개합니다. 빌드 과정은 없습니다.
- **로컬 확인:** `index.html`을 브라우저로 더블클릭해 열면 됩니다(`file://`에서도 동작). 외부 요청은 없습니다. 글꼴도 `assets/fonts/`에 포함돼 있습니다.
- **계산 검증:** `node tests/calc.test.js`(월간 통계), `node tests/deals.test.js`(딜 병합·필터·정렬). 결함이 있으면 목록을 출력하고 종료 코드 1을 냅니다.

## 3. 사용 순서

**매주 (운영자가 칼럼 원고 전달)**
1. `data/issues/NN.js` 추가. 기존 호 파일을 복사해 내용을 교체합니다.
2. `issues/issue-NN.html` 추가. 직전 호 파일을 복사하고 숫자 두 곳(`data-issue`, 데이터 파일 경로)을 바꿉니다.
3. `data/archive.js` 수정
    - 맨 위에 한 줄 추가(`local: true`, `keywords`에 회사·기관명)
    - `latest` 숫자를 올림
4. 홈 히어로·Weekly Deals·Recent Issues·Archive·Deals 페이지, 직전 호의 "다음 호" 링크는 자동으로 바뀝니다.

**매월 (운영자가 KVCA Venture Capital Market Brief 전달)**
1. `data/monthly.js`의 숫자를 새 브리프 값으로 교체합니다.
    - `updated`, `month`
    - 연도별 배열, 업종·업력·유형·LP·회수·코스닥
    - 신규 등록사, 조합결성 상위 10
2. 해가 바뀌면 다음 세 가지를 함께 바꿉니다.
    - `years`·`partial` 배열에 직전 연도 연간 열 추가
    - 누계 두 열을 새 연도로 교체
    - `lastFullYearIndex` 갱신
3. `node tests/calc.test.js`를 실행합니다. 기대값 블록(1번)은 새 달 값으로 고쳐야 통과합니다.

## 4. 계산 규칙 (`assets/js/calc.js`)

| 지표 | 산식 |
|---|---|
| 조 원 환산 | 억 원 ÷ 10,000, 소수 첫째 자리 |
| 증감률 | 당해 ÷ 비교값 − 1. 신규투자·조합결성은 원자료 기재값 사용 |
| 기업당 평균 투자액 | 신규투자 ÷ 피투자기업 |
| 조합당 평균 결성액 | 조합결성 ÷ 조합 수 |
| 연간 실적 대비 달성률 | 당해 누계 ÷ 직전 연도 연간 |
| 기간 누계 | `cumulativeFrom` 연도~직전 연도 연간 합 + 당해 누계 |
| 해외 금액 | 10억 달러 미만 `$110M`, 이상 `$1.5B`(소수 첫째 자리) |
| Deals 중복 판정 | 기업명(대소문자·공백 무시) + 지역 + 금액이 같으면 같은 딜. 대표 기록은 가장 최근 호 |
| Deals 금액순 | 통화가 달라 국내(억 원)·해외(US$)를 나눠 각각 정렬. 유로 등 다른 통화·비공개는 맨 뒤. 동점은 최근 호 → 기업명 |

- 반올림은 소수 둘째 자리에서 합니다. 음수 부호는 −(U+2212)입니다.
- 직접 계산한 값에는 화면에서 `*`를 붙입니다.

## 5. 저장 위치

| 경로 | 내용 |
|---|---|
| `data/monthly.js` | 월간 통계 원자료 |
| `data/archive.js` | 호 목록(검색·Recent Issues·이전/다음 호) |
| `data/issues/NN.js` | 호별 본문 |
| `assets/js/` | 화면 코드(`home.js`, `issue.js`, `common.js`)와 계산(`calc.js`) |
| `assets/css/site.css` | 디자인 |
| `assets/fonts/` | 자체 호스팅 글꼴, SIL OFL 1.1 |

브라우저 저장소(localStorage 등)는 쓰지 않습니다.

## 6. 한도

- 정적 사이트입니다. 로그인·댓글·구독 기능은 없습니다.
- Archive는 최신호를 포함한 전 호를 보여줍니다(기본 5개, 펼치면 전체). 검색은 `data/archive.js`의 제목·대표 딜·keywords만 찾고 본문 전체는 찾지 않습니다.
- 01~22호는 이전 사이트(Genspark)에서 옮겨 새 템플릿으로 표시합니다. 원문 대조 결과는 각 호 상단 정정 안내에 적었습니다.
- 월간 수치는 KVCA 브리프의 연초 누계입니다. 당월 단독 수치는 없습니다(신규 등록사·조합결성 상위 10 제외).
- 데이터 합계가 맞지 않으면 홈 월간 섹션 상단에 "데이터 점검 필요" 경고가 표시됩니다.

## 7. 미검증 항목

- Chromium 외 브라우저(Safari, Firefox) 표시
- 원문을 찾지 못한 기사·수치·딜은 2026.10.27 사이트에서 삭제했습니다(기사 21건, 사실 줄 17건, 딜 1건). 삭제 내역은 각 호 상단 정정 안내에 있습니다.
- 일부 딜 출처는 1차 보도가 아닌 2차 매체(Pulse 2.0 등)입니다.
- 벤처투자법 개정안의 국무회의 통과일(원고 9.22)은 확인하지 못했습니다. 그래서 화면에는 확인된 공포 예정일(9.29)·시행일(2027.03.30)과 기사일(9.25)만 표기했습니다.
- KVCA 자료의 공개 사이트 재게시 이용 조건
